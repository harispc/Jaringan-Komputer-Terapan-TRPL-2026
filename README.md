## 📖 Tentang Repositori
Repositori resmi ini didedikasikan sebagai pusat dokumentasi, modul pembelajaran, slide presentasi, serta panduan praktikum untuk mata kuliah **Jaringan Komputer Terapan** pada program studi **Teknologi Rekayasa Perangkat Lunak (TRPL)**. 

Tujuan utama dari dokumentasi ini adalah untuk membimbing mahasiswa dalam menguasai konsep teoretis sekaligus keterampilan teknis implementasi infrastruktur jaringan komputer tingkat lanjut.

---

## 🚀 Fokus Materi & Topik
* ⚙️ **Advanced Routing & Switching** (OSPF, BGP, VLAN, Q-in-Q)
* 🛡️ **Network Security & Hardening** (Firewall, VPN, ZTNA, Mitigation)
* 📊 **Monitoring & Observability** (Zabbix, Grafana, Telemetry)
* 🧪 **Virtualization & Lab Environment** (Proxmox, EVE-NG, PNETLab)
